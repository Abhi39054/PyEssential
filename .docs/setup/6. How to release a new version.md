# How to Release a New Version

PyEssential uses **tag-based releases**. Pushing a tag such as `v0.1.4` starts the
publish pipeline. Nothing is published from a normal push to `main`.

## Release checklist

1. **Make sure `main` is green.** All tests pass on the latest commit.
2. **Bump the version** in `pyessential/_version.py`:
   ```python
   __version__ = "0.1.4"
   ```
   This is the only place the version is defined.
3. **Commit and push to `main`:**
   ```bash
   git commit -am "chore: bump version to 0.1.4"
   git push origin main
   ```
4. **Create and push the tag.** The tag is the version prefixed with `v`:
   ```bash
   git tag -a v0.1.4 -m "Release 0.1.4"
   git push origin v0.1.4
   ```
5. **Watch the run** in the repository's *Actions* tab.
6. **Approve the deployment** to `pypi-prod` when the job pauses for review.
7. **Verify** the new version on https://pypi.org/project/pyessential/ and the new
   entry under the repository's *Releases* section.

## What the pipeline does

| Step | Job | Notes |
|------|-----|-------|
| 1 | `test` | Python 3.9-3.12 on Ubuntu, Windows and macOS |
| 2 | `build_sdist_wheel` | Fails if the tag does not match `_version.py`; runs `twine check` |
| 3 | `pypi_test_publish` | Uploads to TestPyPI |
| 4 | `pypi_publish` | Waits for manual approval, then uploads to PyPI |
| 5 | `github_release` | Creates the GitHub Release with auto-generated notes and the built files |

## Fixing a mistake

If you tagged the wrong commit or the tag does not match the version, delete the tag
and push it again **before approving the PyPI deployment**:

```bash
git tag -d v0.1.4
git push origin :refs/tags/v0.1.4
```

PyPI never allows re-uploading a version that already exists. If a bad version
reached PyPI, bump to the next version and release again (you can *yank* the bad
version from the PyPI project page).

## If the GitHub Release job fails

The package is already on PyPI at that point. Create the release by hand under
*Releases → Draft a new release*, choose the existing tag, and click
*Generate release notes*.
